# Trundle licensing

Trundle uses different licenses for its code and its images and audio.

## Code — MIT

Trundle's original source code, scripts, build files, level and menu XML, and
associated documentation are licensed under the MIT License. See
[LICENSE-MIT.txt](LICENSE-MIT.txt) for the full terms.

## Images and audio — CC BY 4.0

Trundle's original images, artwork, music, sound effects, and their included
source assets are licensed under the Creative Commons Attribution 4.0
International License (CC BY 4.0). This includes original image and audio assets
in `Game Resources/`, `Base Source/Base Resources/`, and `Support/`.

See [LICENSE-CC-BY-4.0.txt](LICENSE-CC-BY-4.0.txt) for the full terms and the
[Creative Commons license page](https://creativecommons.org/licenses/by/4.0/)
for a summary.

Attribute these assets to **Mobile Bros.**, with **Trundle** as the work's title.
Include the CC BY 4.0 license link, retain supplied credits and copyright
notices, and indicate any changes you make.

## Third-party material

Third-party code and assets retain their existing licenses and attribution
requirements. These project licenses do not replace third-party terms,
including those in `External Source/` and third-party components in `Support/`.
Preserve the license and copyright notices supplied with those components.

The complete component inventory is in
[THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md), with collected source notices in
[licenses/THIRD_PARTY_LICENSES.txt](licenses/THIRD_PARTY_LICENSES.txt).
The cocos2d `fire.png` texture is a third-party asset covered by its accompanying
library license, not the license for Trundle's original artwork.
